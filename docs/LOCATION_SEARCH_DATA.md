# Location search data

The location finder uses the `districts.json` dataset from [Thailand Geography JSON](https://github.com/thailand-geography-data/thailand-geography-json). The source contains **928 districts** with province codes, district codes, Thai names, English names, and postal codes. It is distributed under the MIT License.

The committed client index is a compact projection generated by `scripts/build-location-index.mjs`. Its tuple schema is:

```text
[provinceCode, districtCode, districtNameTh, districtNameEn, postalCode]
```

District search is an interface and navigation feature, not a claim of district-resolution forecasting. Selecting an amphoe or Bangkok khet highlights its parent province and displays that province's ECMWF 0.25-degree screening values. The interface states this limitation next to the search field and in the selected-location readout.
